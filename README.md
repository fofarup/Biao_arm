# Biao_arm

STM32F407ZET6 / Keil ARM Compiler 5 / STM32Cube HAL / FreeRTOS。

## 当前入口

业务流程从 `Task/main_task.c` 的 `MainTask_Run()` 开始。初始化并等待定位就绪后，先执行当前启用的本地测试，再进入 USART6 主机命令处理。调平和底盘闭环每 20 ms 运行，超声波任务每 50 ms 检查并按探头允许间隔更新。

```c
ArmControl_MoveToXYZ(x_mm, y_mm, z_mm);  /* 同时启动，正常轴同步到位，微动可提前到位 */
ChassisControl_MoveRelativeSequential(100, 0, 90, 1000, 1500, 3000);
ChassisControl_MoveRelativeStraightTurn(100, 0, 90, 1000, 1500, 3000);
ChassisControl_MoveDiagonalRelative(0, 100, 0, 100, 150, 800); /* 沿发令时车右前方，保持当前航向 */
Claw_SetAngle(90.0f);  /* 舵机极速模式，只发令，不等待到位 */
Route_Run();  /* 初始化完成后按需调用 */
```

接口返回值应在业务流程中检查；调用示例不代表自动上电执行。`MAIN_TASK_RUN_ROUTE_TEST` 默认 0，改为 1 时初始化后执行一次跑图流程。

## 主机协议摘要

帧格式沿用桌面 `C:/Users/34101/Desktop/new/new/Biao_arm` 的通信约定，位于 `Fun/TX_RX` 和 `Task/main_task`；0001 使用普通车体坐标，0004 使用相对当前车身右偏45°的斜向坐标。上下行统一 **12 字节**：

`FF MODE_H MODE_L X_H X_L Y_H Y_L Z_H Z_L CRC_H CRC_L FE`

CRC16/MODBUS 覆盖下标 **0～8**，包括 FF；XYZ 为 int16，所有 16 位字段均为高字节在前。没有 MAX/ACC/DCC/TIME 字段；0004 用于斜向相对移动。

- 0001：普通车体相对移动，X 向发令时车右、Y 向车前，单位 mm。Z 为逆时针相对转角，单位 °，0 保持当前航向。加/减速度 100/150 RPM/s，最大轮速 800 RPM；实际到位后回复 0011。
- 0002：机械臂绝对 XYZ(mm)，**自动规划共同时间**，同时启动、正常轴同步到位，小位移轴可提前到位；全部参与轴实际到位后回复 0012，失败回复 10FF。
- 0003：夹爪 X=**0～180°**、Y=Z=0，按舵机极速模式执行；指令发送成功后等待 **300 ms** 回复 0012。
- 0004：斜向相对移动，X/Y 轴相对发令时车身整体向右偏45°，+X 向右后、+Y 向右前；Z 仍为相对转角。与0001共用速度参数，实际到位后回复0011。
- 10FF：机械臂错误，X=动作状态码、Y=恢复状态码、Z=是否就绪（0/1）；完整错误码见第 7 节。
- 0020：PD4 实物按键启动事件，X=1 表示启停区 1、X=2 表示启停区 2，Y=Z=0；由下位机主动上报。
- 0011/0012 成功应答 XYZ 全部为 0。0000 无动作；未知码及收到的上行码不会触发运动。

夹爪使用 FashionStar 0x08 单圈角度指令，时间字段固定为 0（极速模式）；调用只需传目标角度。上位机回包等待由 `Task/main_task.h` 的 `MAIN_HOST_CLAW_REPLY_DELAY_MS` 设置，当前为 300 ms，从串口发送成功后开始计时，与舵机速度无关。当前只有 TX 控制，没有位置反馈，因此 0012 表示指令发出且等待结束，不能核验真实到位或夹持成功。

上位机与本地 XYZ 点位共用 `ArmControl_MoveToXYZ()`，只传坐标。先按 `Fun/arm_control.c` 中的速度和加减速度上限求各轴最快时间，再从最长轴时间开始，调整其余轴参数，使正常轴预计到位差不超过 10 ms。量化无法直接对齐时，优先尝试最近的较晚可用时间。三轴用一组指令同时启动，最终等全部 FD 9F 到位反馈。

小位移按本次电机行程判断：在上述最快共同时间内，某轴按加减速上限降至最低 0.1 RPM 仍会提前超过 10 ms，则该轴豁免同步、按最快参数执行。判定一经确定不随时间修正扩大；非零小位移仍执行且等待到位。`ArmControl_GetLastResult()->profile.small_move_mask` 的 bit0/1/2 标记电机 1/2/3 的豁免状态。点位接口不保证末端沿直线运动。

完整帧、执行约定、普通/斜向相对坐标和错误码见《工程文件与功能说明》第 7 节。初始化完成后开启业务接收；若启用了本地测试，主任务先执行完测试再从队列处理上位机命令。当前启用的测试以 `Task/main_task.c` 为准。

## 底盘坐标与顺序动作

普通接口 `ChassisControl_MoveRelativeSequential()` 沿发令时车右/车前移动；斜向接口 `ChassisControl_MoveDiagonalRelative()` 把输入坐标轴整体向右偏45°后交给原控制器。斜向 Y=100 对应车右、车前各约70.71 mm；斜向 X=100 对应车右、车后各约70.71 mm，位移长度保持100 mm。

两种坐标系都采用每次发令时的车身方向。本次终点生成后保持固定，即使动作中旋转车身，也不会移动本次终点。转角参数始终控制真实相对转角，0表示保持当前航向；斜向接口不会额外旋转45°。

行驶段用斜向接口或上位机0004，物料区和加工区用普通接口或0001，每条动作独立选择，不需要全局模式开关。`Route` 的原车体坐标调用继续保留。仅沿斜向单轴且没有旋转/纠偏输出时，理论上由一对轮主驱动；其他轮仍允许参与纠偏，减振效果需实车对比。

顺序动作在新鲜定位进入过渡距离后，保持平移并开始旋转；通过当前最终轮速衔接，不要求先停车。最终完成仍须同时满足 XY、航向误差、低速和连续新采样条件，实际到位后才回复 0011。

参数集中在 `Fun/chassis_control.h`：`CHASSIS_SEQUENCE_TRANSLATE_TOLERANCE_MM` 控制开始转向的距离，`CHASSIS_SEQUENCE_POSITION_TOLERANCE_MM` 和 `CHASSIS_SEQUENCE_YAW_TOLERANCE_DEG` 控制最终精度。具体数值以头文件为准，实车精度需要结合定位反馈验证。

## PD4 一键启动

**接线调整：前方超声波 ECHO 从 PF4 移到 PF2；右方超声波仍接 PF3。** PD4 接低电平有效按键，内部上拉，按下接地，使用双边沿 EXTI4；PF2/PF3 分别使用 EXTI2/EXTI3。

- 短按：按住不超过 1000 ms，稳定松开后上传启停区 1。
- 长按：按住超过 1000 ms，上传启停区 2；持续按住和随后松开都不重复发送。
- 消抖 20 ms。初始化及上述本地测试动作返回后启用；启用时必须先稳定松开，避免上电按住误触发。
- 按键只上传启动事件，后续动作由上位机下发命令。动作执行期间仍可上报按键事件。

```text
启停区 1：FF 00 20 00 01 00 00 00 00 06 53 FE
启停区 2：FF 00 20 00 02 00 00 00 00 06 17 FE
```

时间参数集中在 `Task/main_task.h`；按键处理在 `Task/main_task.c`，组帧发送在 `Fun/TX_RX.c`。完整说明见《工程文件与功能说明》第 7.6 节。
